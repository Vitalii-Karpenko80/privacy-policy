# VoiceFlow — экраны MVP

Визуальный прототип шести ключевых экранов VoiceFlow и UX-переходов между ними.
Опубликован как дизайн-канвас (Claude Design внутри Claude Code): один холст,
на котором каждый `.dc.html` — отдельный артборд iPhone (390×844).

## Основной сценарий

Верхний ряд — главный цикл MVP:

1. **Главный** (`Main.dc.html`) — таймлайн «Сегодня» + большая кнопка микрофона
   «Что нужно запомнить?».
2. **Слушаю** (`Listening.dc.html`) — тёмный экран записи: живая расшифровка +
   waveform. После паузы → `Processing…` → AI Parser возвращает структуру (JSON).
3. **Подтверждение** (`Review.dc.html`) — «Я понял так»: карточки события, задачи и
   контакта; кнопка **Добавить всё**. LLM ничего не создаёт молча.
4. **Готово** (`Success.dc.html`) — что и куда добавлено (Calendar / Reminders /
   Notes / связь с контактом).

Нижний ряд — «второй мозг» (за пределами основного цикла):

- **Контакт** (`Contact.dc.html`) — Personal CRM: события, задачи и заметки,
  связанные с человеком.
- **История** (`History.dc.html`) — журнал команд + поиск на естественном языке
  (после MVP).

## Дизайн-система прототипа

- Нативный iOS 18: системный шрифт (SF), тёплые нейтральные поверхности.
- Один брендовый акцент — индиго `#5B54E6`; тёмный момент на экране записи.
- Цвета категорий: событие `#2F6BFF`, задача `#12A574`, заметка `#E0912B`,
  контакт `#9B4DDB`.
- Без фейкового статус-бара/клавиатуры (рендерятся системой на реальном устройстве).

## Файлы

- `*.dc.html` — исходники артбордов (рабочие файлы, из них пересобирается канвас).
- `canvas.json` — раскладка артбордов и заметки-переходы на холсте.
- `voiceflow-screens.html` — собранный канвас (то, что публикуется).
