# СтройПлан — управление стройкой на планах (прототип в стиле PlanRadar)

Одностраничное веб-приложение (один файл `app/index.html`, без сервера и без
сборки). Данные хранятся **локально в браузере** (`localStorage`) — в духе
privacy-подхода FieldReport: ничего не отправляется на внешние серверы.

Открыть: `app/index.html` в браузере (или по адресу `<сайт>/app/` на GitHub Pages).

Интерфейс — блюпринт-тема (синий чертёж). Локализация РФ: рубли (₽),
ИНН/КПП, единицы измерения, даты. **Ставка НДС задаётся у каждой позиции**
(закупки и сметы), по умолчанию 22%, доступны 22/20/10/0%. КС-2/КС-3 считают
НДС построчно и суммируют (поддержка смешанных ставок). Для проекта/договора
можно выбрать режим **ОСНО** (плательщик НДС) или **УСН** (без НДС) — на УСН
наша реализация (КС-2/КС-3) формируется без НДС («не облагается»), а входящий
НДС по закупкам от поставщиков сохраняется. Настройка — «Акты и КС →
Реквизиты для КС».

## Что умеет
- **Проекты** — несколько строительных объектов, переключение в боковой панели.
- **Финансы и разбивка по проекту** (на «Обзоре») — бюджет затрат и **превышение
  бюджета**, **превышение сметы** (факт затрат vs плановая себестоимость),
  и сводная разбивка со ссылками: смета/себестоимость, график строительства,
  закупки/поставки (+склад), договоры.
- **Склад · остатки** (вкладка в «Закупках») — поступление из закупок (статус
  «Получено»/«Оплачено») минус списания = остаток; средняя цена и стоимость
  остатка; списание материала; выгрузка в CSV.
- **Договоры и спецификации** — отдельный раздел: договоры (тип, контрагент,
  ИНН, сумма, статус) со **спецификацией** (позиции) и **привязкой к зданию**;
  вкладка **«Здания/объекты»** с площадью, этажностью и суммой договоров.
- **Планы/чертежи** — загрузка изображения плана этажа (несколько на проект),
  зум колесом, панорама перетаскиванием, «вписать в экран».
- **Метки на плане** — кнопка 📍, клик по плану ставит метку и создаёт задачу.
  Цвет метки = статус задачи. Наведение на список подсвечивает метку.
- **Задачи/дефекты** — тип (дефект/задача/осмотр), приоритет, исполнитель, срок,
  описание, привязка к плану. Список с поиском, фильтрами и сортировкой.
- **Карточка задачи** — смена статуса в один клик, журнал изменений,
  комментарии, **фотофиксация** (фото сжимаются перед сохранением).
- **Смета и себестоимость** — позиции работ по разделам РД (АР, КЖ, КМ, КМД,
  ОВ, ВК, ЭОМ, СС, ПС, ГП, БЛ…), договорная цена и себестоимость за единицу.
  Автоанализ: договорная стоимость, себестоимость, плановая прибыль,
  рентабельность, % выполнения. **Разбивка по разделам** (стоимость /
  себестоимость / прибыль / маржа / выполнено). Выгрузка сметы в CSV.
- **График строительства** — диаграмма Ганта по позициям сметы:
  - **план/факт**: пунктир планового прогресса на полосе, красная заливка при
    отставании, сводка «план на сегодня / факт / отклонение / работ с
    отставанием» (взвешено по стоимости);
  - **зависимости** работ (finish-to-start) со стрелками и **критический путь**
    (★, подсветка) — расчёт по CPM;
  - **перетаскивание** полос мышью (сдвиг и растяжение краёв) — правит даты;
  - масштаб **недели / месяцы / кварталы**, линия «сегодня», выгрузка в CSV;
  - маркеры привязанных поставок на полосе работы (красный — материал приходит
    позже начала работы).
- **График поставок** (вкладка в «Закупках») — таймлайн от заказа до плановой
  поставки, цвет по статусу (получено / в пути / просрочено), масштаб
  недели/месяцы/кварталы, линия «сегодня». Можно **связать поставку с работой** —
  красным подсвечивается поставка позже начала связанной работы.
- **Акты и формы КС** — формирование **КС-2** (акт о приёмке выполненных работ)
  за период с выбором объёмов (двигает «выполнено» в смете); **КС-3** (сводная
  справка о стоимости: с начала работ / с начала года / за период); **КС-6**
  (журнал производства работ). Формы генерируются как готовые печатные
  документы (HTML A4 → «Печать / Сохранить в PDF») с реквизитами договора
  (Инвестор/Заказчик/Подрядчик/Стройка/Объект), НДС 22% и подписями.
- **Закупки** — материалы/работы с поставщиками (ИНН), количество и единицы,
  цена с НДС и авторасчёт НДС 22%, статусы (запланировано → заказано →
  получено → оплачено), номера счетов/УПД, сводка бюджета.
- **Тендеры** — предмет, НМЦ (бюджет), срок; заявки поставщиков (ИНН, цена,
  срок), выбор победителя, перевод победителя в закупки.
- **История проектов** — активные и архивные проекты с метриками,
  архивация/восстановление, сводная лента событий по всем проектам.
- **Интеграции с бухгалтерией РФ** — 1С:Бухгалтерия, 1С:УНФ, СБИС, Контур,
  МойСклад, Диадок (ЭДО): реквизиты организации, настройка подключений и
  **выгрузка** закупок в формат 1С (XML/CommerceML) и CSV, реестр счетов,
  список поставщиков (CSV — с BOM для Excel).
- **Команда** — участники проекта и их текущая загрузка.
- **Экспорт/импорт** — резервная копия всех данных в JSON-файл.

При первом запуске загружаются демо-данные (проекты, план этажа, задачи,
закупки, тендеры, поставщики), чтобы сразу посмотреть, как всё работает.

## Про интеграции: важно
Живой обмен по API/ЭДО с бухгалтерскими системами требует серверной части
(хранение ключей, вызовы API, ЭДО). В прототипе реализована настройка
подключений и рабочая **выгрузка файлов** в форматах, которые эти программы
импортируют. Это осознанное ограничение клиентского приложения без бэкенда.
